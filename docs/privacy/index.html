CLI for Slack (unofficial) Support Source

Privacy policy and terms

This policy covers the slack command from the npm package @alleneubank/slack-cli, its Slack app "CLI for Slack (unofficial)", and this website. The project is maintained by Allen Eubank (Unruly Systems) and is not made, affiliated with, or endorsed by Slack Technologies, LLC.

The project collects no data. The source code at github.com/alleneubank/slack-cli is the privacy policy and the terms: what the software does is exactly what the code does.

What data is collected

None. The project has no server, database, analytics, telemetry, or crash reporting.

  • Your Slack token is stored only on your computer, in ~/.config/slack-cli/credentials.json with permissions that let only your user account read it, or in the SLACK_TOKEN environment variable if you set it. The developers never receive it.
  • Your Slack data (messages, files, channels, people) goes directly between your computer and https://slack.com when you run a command. It is not sent to the developers or anyone else.
  • The sign-in page (https://alleneubank.github.io/slack-cli/callback/) receives a one-time authorization code from Slack in its address and, in your browser, passes it to slack login on your computer or shows it for you to paste. The page has no analytics and sends the code nowhere else. The code expires within minutes, works once, and cannot be used without a secret that slack login generates and keeps on your computer. The page is hosted on GitHub Pages; GitHub may keep standard request logs under the GitHub Privacy Statement.
  • Updates: the CLI does not check for updates in the background. slack --update contacts the npm registry only when you run it.
  • Support email: if you write to us, we receive what you send and use it only to answer you.

How data is used

The CLI uses your token only to call the Slack Web API methods you run, on your behalf. The developers do not use, receive, sell, or share any Slack data.

How long data is kept

  • Your token stays on your computer until you remove it with slack logout (one workspace) or slack logout --all, or delete the credentials file.
  • Tokens do not expire on their own. slack auth revoke invalidates the current token at Slack, and a workspace admin can remove the app from the workspace's app settings.
  • Support emails are kept only as long as needed to answer them, then deleted.

Access, transfer, and deletion

The developers hold no Slack data about you, so there is nothing for us to access, transfer, or delete. Everything the CLI stores is in a file on your own computer that you can read, move, or delete at any time.
