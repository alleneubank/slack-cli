Support

Email allen@unrulysystems.com with what you ran and what happened. No account is needed, and we answer within two business days. If you have a GitHub account, you can also open an issue. Report security problems privately, as described in the security policy.

Never send your Slack token or the contents of ~/.config/slack-cli/credentials.json. The CLI never prints tokens, so its output and error messages are safe to share.

Common questions

The browser says it cannot reach 127.0.0.1

The CLI is running on a different machine from your browser, for example over SSH. Run slack login --paste, approve in the browser, and paste the code the page shows into the terminal.

Login fails because port 8912 is in use

Another slack login may still be waiting; stop it and try again, or use slack login --paste, which does not listen on a port.

A command fails with missing_scope

Run slack login --write to grant write access. The error names the command to run when login can grant the scope.

My workspace does not allow the app

Some workspaces restrict third-party apps; ask a workspace admin to approve it. You can also create your own Slack app from the project's app manifest and set SLACK_CLIENT_ID to its client id.

Working with several workspaces

Each slack login adds a workspace. slack workspaces list shows them (never the tokens), and slack workspaces use T0123456789 switches the current one.

Removing access

slack auth revoke invalidates the token at Slack, slack logout removes it from your computer, and a workspace admin can remove the app in the workspace's app settings.
