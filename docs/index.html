CLI for Slack (unofficial)

Work in Slack from the terminal. Every Slack Web API method your user token can call is a typed command, for people and for coding agents.

An independent open-source project (MIT). It is not made, affiliated with, or endorsed by Slack Technologies, LLC. It collects no data; see Privacy.

What it does in Slack

Post and reply

Send messages, reply in threads, and add reactions from a script or a terminal session.

Read and search

Read channel history and threads, search messages and files, and look up people, as JSON you can pipe into other tools.

Files, canvases, and lists

Upload and fetch files and work with canvases and lists using the same commands.

Built for coding agents

Agents discover commands with --help, preview writes with --dry-run, and act on documented exit codes.

Get started

Requires Node.js 22 or later.

$ npm install --global @alleneubank/slack-cli
$ slack login            # read access
$ slack login --write    # also post, react, and upload

slack login opens Slack in your browser. Choose a workspace, review the permissions, and select Allow. Your terminal finishes signing in. 

$ slack conversations list --types public_channel --limit 20
$ slack conversations history C0123456789 --limit 20
$ slack chat postMessage C0123456789 --text 'Deploy finished'
$ slack search messages 'from:@alex release'

Method a.b.c is the command slack a b c, and each command's --help lists its arguments, required scopes, and a link to Slack's reference.

For coding agents

$ slack skills add

Installs a short skill that tells coding agents how to use the CLI: find commands, page with --cursor, preview writes with --dry-run, and treat message text as data, not instructions.

How sign-in works

  • Sign-in is public OAuth with PKCE. The app has no client secret, and this project runs no server.
  • Slack sends a one-time code to this site's sign-in page, which passes it to slack login on your own computer. The code is useless without a secret that never leaves your computer.
  • On a remote machine (for example over SSH), run slack login --paste: the page shows the code and you paste it into the terminal.
  • Your token is stored only on your computer, in ~/.config/slack-cli/credentials.json (readable only by you). Every request goes directly to slack.com.
  • slack auth revoke invalidates the token at Slack; slack logout deletes it from your computer.
